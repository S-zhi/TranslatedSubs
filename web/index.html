连接 MCP Server 后，AI Agent 可以帮你探测视频、创建翻译任务并跟踪处理进度。下方说明会一直保留在队列上方，随时可以查看。

使用说明

从连接到拿到字幕，只需三步

01—03
  1. 01
    连接 MCP 客户端

    在 Claude Desktop、Cursor 等支持 MCP 的客户端中添加本项目 Server。

  2. 02
    告诉 AI 你要处理的视频

    提供视频链接和目标语言，AI 会先检查服务配置与视频可访问性。

  3. 03
    等待任务完成并下载

    任务会异步进入下方队列；完成后可在任务详情中查看字幕与产物。

MCP 服务器如何接入

本地 stdio 连接 · 推荐桌面客户端使用

claude_desktop_config.json
{
  "mcpServers": {
    "translatedsubs": {
      "command": "uv",
      "args": ["run", "python", "-m", "src.mcp_server.server"],
      "cwd": "/Your Project Path"
    }
  }
}

先启动业务 API，再重启 MCP 客户端。远程部署可使用 streamable-http，默认地址为 http://127.0.0.1:3001/mcp。
