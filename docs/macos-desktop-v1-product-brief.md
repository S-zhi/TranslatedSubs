# TranslateSub macOS 桌面首版：产品约定与交付计划

- 记录日期：2026-10-17。
- 状态：产品范围已由用户确认；本文记录讨论结论与验收目标，不代表功能已经实现或通过验收。
- 目标周期：三天完成首版开发与验收准备。讨论尚未约定实施开始日期，因此不换算为固定发布日期。
- 发布原则：面向陌生用户正式公开发布，签名、公证和核心验收条件未满足时顺延发布。
- 当前授权：整理并保存讨论文档。本文不构成购买服务、上传发行资产或对外发布的授权。

## 1. 一句话目标

让学习者／研究者下载安装 TranslateSub 后，无须配置开发环境、服务或 API Key，就能将英文课程、讲座和访谈转换为带中英双语硬字幕的视频；首次自动准备模型，后续直接使用。

用户的核心诉求是“像普通软件一样，下载安装就能用”。使用一段时间后可以配置云端模型提高识别效率，但这项增强已明确放到下一版。

## 2. 用户与核心使用场景

### 目标用户

首版优先服务学习者／研究者，围绕理解和回看英文学习资料优化体验。

### 核心流程

1. 用户下载 Apple Silicon 版本 DMG，安装并打开独立桌面应用。
2. 首次打开时，应用自动准备基础转写和翻译模型，显示下载大小、进度与当前状态；失败可以重试。
3. 用户粘贴 YouTube 公开视频链接，或选择电脑里的本地视频。
4. 应用完成视频获取、本地英文转写、简体中文翻译及中英双语字幕压制。
5. 用户在应用中查看任务进度、预览结果，导出带硬字幕的 MP4，也能单独获得字幕文件。
6. 用户可以关闭窗口，让任务继续在后台执行，并从菜单栏重新打开应用。
7. 应用自动检测新版本，展示版本与更新说明，引导用户下载新版 DMG。

### 零配置的定义

- 用户无需安装 Python、Redis、FFmpeg 等运行依赖，无需使用命令行，也无需编辑配置文件。
- 用户无需选择基础模型或填写云端 API Key，即可完成首个字幕视频任务。
- 首次使用允许联网自动下载模型，因此“零配置”不等于“首次打开无等待”或“安装后立即离线可用”。
- 运行依赖由应用自行提供或管理，具体技术方案尚待确定。
- 模型准备完成后，首版本地转写、翻译和字幕压制不依赖云端推理服务。

## 3. 已确认的首版范围

| 维度 | 已确认要求 | 边界 |
| --- | --- | --- |
| 平台 | Apple Silicon，也就是 M 系列 Mac | Intel、Windows、移动端不作为本次首版交付目标 |
| 安装与界面 | DMG、独立桌面窗口，复用现有 Web 界面 | 用户无需手动启动服务或输入本地地址；桌面框架尚未选定 |
| 输入 | YouTube 公开视频＋本地视频 | 其他网站、登录后可见内容不是首版必验来源 |
| 首次准备 | 自动下载基础模型，展示大小、进度，失败可重试 | 不把全部模型放入 DMG 作为本次默认方案 |
| 语言 | 英文音视频转写，英文→简体中文翻译 | 多语种自由组合不是首版承诺 |
| 输出 | 中英双语硬字幕 MP4，另保留可单独获取的字幕文件 | 默认字幕压入画面，无法关闭；编码耗时计入处理时间 |
| 推理方式 | 首版完成本地闭环 | 云端转写、翻译增强放到下一版 |
| 地区 | 国内、海外均验收应用下载、模型准备和更新检测 | 不承诺应用改变用户所在网络对 YouTube 的访问条件 |
| 更新 | 自动检查，展示版本与更新说明，提供新版 DMG 下载入口 | 用户安装新版；首版不做应用内自动替换、安装和重启 |
| 发行 | 面向陌生用户公开发布，具备独立安装说明和可理解的错误提示 | 正式公开版必须完成开发者签名与 Apple 公证 |
| 费用 | 必要发行开支可以纳入方案 | 先列具体用途、金额，再逐项决定；预算上限尚未确定 |

## 4. 长任务与应用退出行为

以下行为已确认纳入首版：

- **关闭窗口**：任务继续在后台运行，用户可以从菜单栏重新打开。
- **主动退出应用**：有任务运行时提醒用户确认，确认退出后才停止处理并释放资源。
- **重新打开应用**：保留任务记录和已经完成的结果，中断任务提供重试入口。
- **重试边界**：首版不保证从中断时间点或中断阶段继续处理，不把重试等同于断点续处理。
- **更新提示**：不打断正在处理的视频，不擅自退出应用或安装新版。

系统睡眠、异常退出等具体恢复策略还需在工程设计中明确；不得据此对外承诺尚未验证的持续运行或断点恢复能力。

## 5. 验收标准

下列均为交付目标。本文没有附带已完成的安装、性能、字幕质量或国内外网络验收结果。

### 5.1 干净设备与首次使用

在没有开发环境的目标 Mac 上验证：

- 从公开下载入口获得 DMG，按说明独立安装并打开。
- 不安装外部开发工具，不手动配置服务，不填写 API Key。
- 模型自动准备流程能够展示状态、完成准备，失败后提供可操作的重试入口。
- 用户能够独立完成提交、查看进度、预览和导出。
- 正式公开发行文件完成开发者签名和 Apple 公证，并验证下载后的安装体验。

最低支持的 macOS 版本和具体安装包体积尚未确定，需要结合依赖兼容性与构建结果落实。

### 5.2 核心样本与处理时间

| 项目 | 验收目标 |
| --- | --- |
| 硬件 | M1、8GB 内存 |
| 输入样本 | 一段 60 分钟、1080p 的英文课程视频 |
| 性能计时前提 | 基础模型已经准备好，视频已经在本地 |
| 计时范围 | 本地转写＋英文到简体中文翻译＋中英双语硬字幕压制 |
| 耗时上限 | 两小时 |
| 不计入该上限 | 首次模型下载、YouTube 视频下载 |
| 成品 | 可正常播放并直接看到中英双语字幕的 MP4，以及可单独获取的字幕文件 |

两小时是用户接受的验收上限，不是当前实现的速度预测。发布前需要记录实际耗时与资源使用。若目标设备上未达标，应先优化，或重新确认支持范围与性能目标，不能直接降低标准并宣称验收通过。

YouTube 下载流程需要单独验收，不能只用本地样本替代。

### 5.3 字幕质量

以同一段 60 分钟英文课程验证：

- 完整处理整段内容，没有整段漏字幕。
- 没有持续明显错位。
- 没有大段未翻译。
- 抽查开头、中间和结尾，中文能够表达主要意思。
- 允许少量措辞生硬和专业术语错误。
- 明确标注字幕由机器生成。

首版没有约定逐字正确率、术语准确率或“接近人工翻译”等数值承诺。具体样本、抽查时间点和问题记录应在验收时保留，避免只凭短片演示判断长视频质量。

### 5.4 国内外网络与 YouTube 边界

国内和海外都必须验证：

1. 应用安装包可以下载。
2. 首次模型准备可以完成。
3. 应用能够检测更新并引导下载新版。
4. 本地视频可以独立完成整个处理流程。

YouTube 下载以用户网络能访问目标视频为前提。无法访问时，应用需要明确说明原因，提供重试和本地视频入口；下载页与应用提示应说明这一边界。即使网页可访问，实际下载成功与否仍需要验收。

### 5.5 任务与更新体验

- 关闭窗口后任务继续，能够重新打开查看进度。
- 主动退出时对运行中任务进行确认提示。
- 再次打开保留任务记录、已完成结果，中断任务可重试。
- 发现新版本后显示版本与更新说明，提供可用的 DMG 下载入口。
- 更新提示不会中断当前任务。
- 下载、模型准备或处理失败时，用户能够理解当前失败阶段和下一步操作。

## 7. 三天交付顺序

这是已讨论的执行顺序，具体工作量需要第一天验证后校准。三天是集中迭代目标，不豁免正式发布门槛。

### 第一天：验证关键可行性

- 在 M1／8GB 目标设备上跑完整的 60 分钟英文课程。
- 测量转写、翻译、硬字幕压制的分段与总耗时，记录资源使用，抽查字幕质量。
- 验证桌面运行依赖与首次模型准备能够由软件自动管理。
- 验证国内外模型、安装包及更新信息下载路径的可行性。
- 同步落实 Apple 开发者发行条件、证书与公证准备，列明必要费用。

产出：性能和质量基线、依赖打包方案、分发与签名阻塞项。若关键条件不成立，尽早调整实现方案；涉及改变已确认产品承诺时再与用户确认。

### 第二天：完成桌面使用流程

- 接入独立桌面窗口和应用生命周期。
- 完成所需运行依赖打包或自动管理。
- 完成首次模型准备、任务进度、错误提示、重试、结果预览和导出。
- 完成关闭窗口继续后台处理、主动退出确认，以及重启后的任务记录与结果保留。
- 接入自动版本检查和新版 DMG 下载提示，给第三天保留完整验收时间。

产出：可安装、可完成完整任务的候选 DMG。

### 第三天：验收并准备公开发行

- 在没有开发环境的 Mac 上走完整安装与首次使用流程。
- 验收 YouTube 公开视频与本地视频，核对性能、字幕质量、任务退出和重试行为。
- 完成国内和海外下载、模型准备、版本检测及更新链接验证。
- 完成开发者签名、Apple 公证，以及实际下载文件的安装检查。
- 准备公开下载入口、安装说明、基本使用说明、已知限制和版本更新说明。

产出：满足门槛的公开发行候选包和验收记录。签名公证或核心验收未通过时继续修正并顺延发布；不自动改为发布未签名预览版。

## 9. 下一版方向与首版取舍

- 下一版优先提供云端模型增强，让用户在初步使用后按需配置，提升处理效率和质量。
- 首版暂不选择具体云厂商，也不承诺任意商业服务只填 Key 即可使用。
- 多语种、Intel 和其他操作系统、更多网站、登录态视频、应用内自动安装更新不纳入本次必交付范围。
- 仓库已有其他能力可以继续保留，但本轮产品优化以学习者的零配置桌面闭环为主线。
